1. Set JAVA_HOME
set "JAVA_HOME=C:\Program Files\Java\jdk1.8.0_202"


Make sure this points to the JDK, not the JRE. The JDK contains keytool.exe and jarsigner.exe.

2. Update PATH to include bin directories
set "PATH=%JAVA_HOME%\bin;C:\Program Files\Java\jre1.8.0_202\bin;%PATH%"


This ensures both the JDK and JRE binaries are available in the session.

3. Verify

Open a Command Prompt and run:

java -version
keytool -help
jarsigner -help


You should see the versions and usage instructions. If so, your environment is correctly set.

4. Run Your Signing Script

After setting JAVA_HOME and PATH in the same command prompt session, simply run your batch script:

D:\Java\bitdreamit-astm\sign\sign_plugin.bat
